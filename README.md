### What I learned

This project pushed my brain 🧠 to its absolute limits and taught me a ton.

It gave me real hands-on experience with the full game dev cycle, and I came away with massive respect for game developers - especially solo ones.

**About Pygame**: it's powerful and flexible, but definitely not for the faint of heart.  
You can build almost anything with it... yet for anything bigger than a small project, I'd reach for something like **Godot** or **Unity** next time.

# 🚀 Typing Shooter: Space Adventure

![Python](https://img.shields.io/badge/Python-3.13.2-blue) 
![Pygame](https://img.shields.io/badge/Pygame-2.6.1-yellow) 
![License](https://img.shields.io/badge/License-MIT-green) 

**A fast-paced typing shooter built with Pygame.**  
Type words to fire bullets, destroy incoming enemies, and survive endless waves in deep space.  
Perfect for improving your **typing speed, accuracy, and reflexes** - or just blowing things up.

Defend your spaceship against relentless meteors, kamikaze drones, proximity mines, gunships, and massive battleships. Words appear above each enemy - type them quickly and correctly to shoot. The faster and more accurate you are, the longer you survive.

## 👾 Enemy Types

### ☄️ Meteors

Brainless chunks of floating rock - about the size of a city bus - hurtling through space.  
I swear I didn’t program them to chase you... but they *always* drift straight toward your ship.

## 📥 Download & Install

### 🔹 Get the Game
Download the latest build from **GitHub Releases**:  
👉 **https://github.com/AshwaniDev101/PyGame-TypingShooter/releases/latest**

Available for **Windows** only.

### 🔹 Install
1. Download the ZIP from the latest release  
2. Extract it anywhere  
3. Run `TypingShooter.exe`  
4. That's it - enjoy!
